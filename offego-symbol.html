02 / 07
DROP △ 드롭 트라이앵글
역삼각형 슬로건 직결

역삼각형이 아래로 녹아내린다. "Drop" 슬로건의 시각적 번역. 단순하고 강하지만 고유성은 낮음.

03 / 07
DEAD SIGNAL 데드 시그널
OFF 개념 흡입기 연결

"OFF"EGO — 신호가 꺼지는 순간. 브랜드명과 개념이 직결. 제품 카테고리(흡입기=호흡=생명신호)와도 연결.

04 / 07
ANTI-EGO EYE 안티이고 아이
이고 디졸루션 반항

눈을 보지 않겠다 — 타인의 시선과 사회적 자아를 거부. X 눈은 죽음과 해방 동시에. Playboy 심볼 대응.

05 / 07
VOID CROWN 보이드 크라운
권위 거부 반도식적

왕관을 뒤집어 내부를 공허로 채운다. 사회가 씌운 왕관을 거부. Liquid Death의 반전 코드와 같은 맥락.

06 / 07
UNTETHER 언테더
자아 해방 자유

인간 실루엣의 하체가 지워진다. 사회적 자아로부터 분리되는 순간. 가장 서사적이지만 단순화 필요.

07 / 07
STATIC / GLITCH 스태틱
글리치 미학 디지털 반항

O자 형태가 글리치로 끊긴다. OFF의 'O'와 연결. 브랜드명 자체가 심볼로. 워드마크형 심볼로 발전 가능.

— Recommendation
PUPPET VOID가 가장 강하다.
여기에 역삼각형을 얹어라.
손바닥이 아래를 향하고, 줄은 있지만 인형이 없다는 개념은 이 카테고리 어디에도 없다. 자아 해방의 서사를 하나의 형태로 압축한 유일한 심볼이다. 여기에 역삼각형 프레임을 씌우면 — Brain Dead의 기이함과 Fragment의 절제가 동시에 성립한다.
