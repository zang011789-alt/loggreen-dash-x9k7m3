OFFEGO / Symbol Direction 02
NUMBERS DON'T LIE.
BUT THEY CAN REBEL.
숫자를 뒤집고, 조합하고, 부수고, 다시 읽는다.
반항은 새로운 기호를 만드는 것에서 시작한다.
01 — ZERO = EGO
01-A / OFF + 0
OFF + ZERO
OFFEGO의 EGO → 숫자 0으로 치환.
"자아를 꺼서 0으로 만든다"는 의미를 로고 자체에 박아버림.
01-B / EGO = 0
EGO Strikethrough
EGO 마지막 글자 O를 숫자 0으로 바꾸고 취소선.
"내가 0이다 = 그들이 만든 나를 지운다"
01-C / ∅ NULL
∅ Null Symbol
수학에서 "공집합"을 뜻하는 기호.
자아가 텅 빈 상태. 비어있음이 자유.
01-D / −0
Minus Zero
수학적으로 의미 없는 기호.
규칙 밖에 존재하는 OFFEGO의 포지션.
02 — FLIPPED & INVERTED
02-A / 6 ↔ 9
6 / 9 Duality
보는 방향에 따라 6이 9가 되고, 9가 6이 된다.
관점을 뒤집는 것 = 반항의 시작.
로고 단독 심볼 후보 중 가장 간결함.
02-B / 1 뒤집기
Inverted 1
"1"은 개인, 유일, 독립의 상징.
거꾸로 서있는 1 = 시스템 바깥에 홀로 선 자아.
02-C / 거울 7
Mirror 7
7을 거울로 마주보게 배치.
창살처럼 맞닿는 형태 — 탈리마크 방향과 연결 가능.
03 — NUMBER COMBINATIONS
03-A / 0FF
0FF — Zero as O
OFF의 첫 글자 O를 숫자 0으로 치환.
"전원을 끄다" + "자아를 0으로 리셋".
03-B / 0/∞
Zero to Infinity
자아 = 0으로 비울 때
가능성 = 무한대가 된다는 방정식.
03-C / 01
Binary 01
시스템의 언어 = 이진수 0과 1.
그 코드로 짜인 나를 다시 읽는다.
03-D / #1
#1 — HashTag One
해시태그 = 분류 시스템.
#1 = 카테고리 없는 1위 — 규칙 바깥의 1등.
04 — BROKEN NUMBERS
04-A / 숫자가 부서진다
0 Shatters Into ∞
0(자아)이 부서지는 순간 ∞(무한)가 된다는 서사.
로고 애니메이션으로 쓰기 완벽한 구조 — 정적 마크는 깨진 0 단독으로.
04-B / 7이 꺾인다
Broken 7
7의 수평선이 부러지는 순간.
"한계선이 꺾이는 지점" — 무기처럼 읽힐 수도 있음.
05 — SYSTEM CODES
05-A / ERROR 404
404 Not Found
"자아를 찾을 수 없음".
시스템이 나를 정의 못 하는 상태.
서브그래픽/태그라인으로 강력함.
05-B / 000
000 — Total Reset
세 자리 0 = 완전한 초기화.
"그들이 만든 나를 모두 지우고 남은 것."
05-C / −1
Minus One
존재에서 하나 빼기.
"나를 한 겹 벗어낸 상태"의 기호.
단순하면서 철학적으로 가장 날카로움.
05-D / ∞
∞ — 8 Sideways
8을 옆으로 눕히면 무한대.
한 숫자가 다른 의미로 전복되는 것 자체가 OFFEGO.
06 — WORDMARK HYBRIDS
06-A / 0FF3G0
0FF3G0 — Leet Speak
O→0, E→3 으로 치환하는 리트스피크(Leet) 방식.
해커 문화 + 반항적 언어 감각. 서브 로고 or 한정판 각인용.
06-B / OFF · EG · 0
OFF / EGO / 0 — Triptych
브랜드 이름을 3개로 분해 + 의미 부여.
0이 마침표이자 목적지가 되는 구조.
PICK LIST — 가장 날카로운 것들
−1 "나를 한 겹 벗어낸 상태" — 가장 철학적이고 단순함
0FF 브랜드 이름 + 리셋 = 자연스러운 합체
6/9 보는 방향에 따라 달라지는 심볼 — 제품에 각인 시 강함
∅ 공집합 — 자아가 텅 빈 상태의 시각화
404 "자아를 찾을 수 없음" — 서브 그래픽으로 강력
NOTE
숫자 방향은 탈리마크와 충돌하지 않음.
탈리 = 시간/감옥 서사
숫자 = 자아/시스템 서사

둘을 합칠 수도 있음 — 예: 탈리마크 안에 −1을 새기거나, 감옥 벽에 0FF를 긁어놓은 느낌.
